## 3. 合同逐项比对与代码审查细节

### 3.1 单行表格智能还原 (`desktop/src/lib/markdown.ts`)
- **连写标记还原**：
  - 正则 `text.replace(/\|\s*\|/g, "|\n|")` 将大模型在单行内通过 `||` 连写的所有表格行（表头、分隔线 `|---|---|`、数据行）精准还原为标准 GFM 多行换行格式；
  - 配合前置段落与表格断行规则 `text.replace(/^([^|\n].*?)(\|.+?\|\s*\n\s*\|[-: ]+?\|)/gm, "$1\n\n$2")`，确保单行或紧贴段落的表格在进入解析阶段前均成为独立、合规的多行表格块；
- **HTML 语义化表格渲染**：
  - `markdownToHtml` 顺利将还原后的表格解析并渲染为标准 `<table>`、`<thead>`、`<tbody>`、`<th>`、`<td>` 结构。

### 3.2 标题与正文粘连解构三层防线 (`desktop/src/lib/markdown.ts`)
- **第一层（加粗/引用/表格符号断行）**：
  - 正则 `(#{1,6}\s+[^\n*|【]*?)\s*(\*\*|【源|\|)` -> `$1\n\n$2`，解决如 `### 1.1.1 建设地点**项目名称**` 等符号粘连；
- **第二层（工程咨询中文句式词智能断行）**：
  - 正则 `(#{1,6}\s+\d+(?:\.\d+)*\s+[^\s#\n]{2,20}?)\s*(项目|本项目|该项目|本工程|工程|根据|按照|依据|经查|经核实|经测算|经评估|经分析|经过|为贯彻|为实现|为满足|为了?|为进一步|总投资|总用地|总建筑面积|规划建设|建设内容|建设规模为|建设地点位于|主要建设内容|主要指标如下|主要包括|涵盖|包含|如下表|如下所示|如下：|由|针对)([\u4e00-\u9fa5])` -> `$1\n\n$2$3`；
  - 精准识别并解构如 `### 1.1.6 主要技术经济指标项目主要技术经济指标如下表所示：`、`### 1.1.7 绩效目标本项目...`、`### 1.2.1 基本信息项目单位为...` 等最低级标题与正文连写情况；
- **第三层（已知大纲标题库精确前缀匹配）**：
  - 支持传入 `knownHeadings` 参数，遍历大纲标题并执行 `^(#{1,6}\\s+${escaped})\\s*([^\\n]+)$` 精准断行；
- **标题树纯净保障**：
  - `extractSubHeadings` 统一调用 `normalizeMarkdown`，提取的子标题标题文字纯净（如提取出 `1.1.6 主要技术经济指标`，不再夹带后续正文文本）。
