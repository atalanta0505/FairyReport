## 2. 保留决定（引自 v1）

D1 资料可上云；D2 平台统一供 LLM Key；D3 腾讯云轻量；D4 Tauri2+Vue3+TS；D5 断网不可用；D6 MSI；D8 无 ICP、邮件走 QQ SMTP；D9 单仓（backend/、desktop/）。

## 3. 重要风险提示（产品负责人已知悉方向，细节见 T2 合同）

平台供 Key 且暂不收费 ⇒ LLM 成本全部由产品负责人承担。必须保留**最小计量与硬性用量上限**（按用户/日的 token 上限，可配置），防止成本失控。此为 D2 的强制配套项。
