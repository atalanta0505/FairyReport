# 产品决定记录 — V2 桌面正式版 v1

- 状态：已确认（产品负责人 = 用户本人，不写代码；开发由 PMC 三角色 agent 承担）
- 记录日期：2026-08-19
- 来源：两轮产品讨论（聊天），本文为首份版本化存档

## 1. 背景与目标

FairyReport v1.0.5（Streamlit + LLM + RAG 工程咨询报告生成工具）改造为 **Windows 桌面正式版**：

- Streamlit 启动/加载过慢，需更换前端与技术架构；
- generic_knowledge（通用知识：模板 JSON + 政策文献 + 预编译向量库）**不得**随安装包分发，必须上云；
- 正式版采用账号制，两种收费模式：**按单个项目收费** 与 **付费订阅**；
- 注册方式：邮箱 + 验证码（或验证链接）。

## 2. 已确认决定

| # | 决定 | 产品负责人原话（摘要） |
|---|---|---|
| D1 | 项目资料允许上云保存（方案 A：全云后端 + 瘦桌面客户端） | "项目资料可以上云保存" |
| D2 | LLM Key 由**平台统一提供并计费**，用户不再自带/自配 Key（取代第一轮的"用户自带 key"） | "LLM Key还是让用户别自己配置了，平台统一供Key/计费" |
| D3 | 云平台：腾讯云轻量应用服务器 | "用腾讯云轻量服务器" |
| D4 | 技术栈不限纯 Python；由 Maker 实现全部代码（采纳 Tauri 2 + Vue 3 + TypeScript 桌面端） | "这要看你的maker是不是什么都能写" |
| D5 | 断网不可用，无需离线设计 | "断网不可用" |
| D6 | 安装包：MSI（用户熟悉 MSI，不熟悉 NSIS） | "见到MSI比较多一些" |
| D7 | 收费模式：按单个项目收费 + 注册账号付费订阅，两种并存 | "按单个项目收费以及让用户注册账号并付费订阅" |
| D8 | 无 ICP 备案；邮件通道 MVP 用 QQ 邮箱 SMTP | "没有ICP，邮件通道先QQ的就行" |
| D9 | 单仓结构：本仓库新增 `backend/`、`desktop/` 目录，不另开仓库 | "同意" |

## 3. 架构结论（由 D1-D9 推导）

```text
[Tauri 2 + Vue 3 桌面端 (MSI)]
      │ HTTPS
[腾讯云轻量: FastAPI + PostgreSQL + Chroma + ONNX(MiniLM) 嵌入]
      ├─ 账号：邮箱验证码注册/登录（QQ SMTP，MVP）
      ├─ 权益与计费：项目配额 / 订阅期 / LLM token 计量 / 平台 Key 池
      ├─ 资料：上传→解析→分块→向量化（pipeline.py 移植）
      ├─ generic KB：云端模板 + 政策文献向量检索（不进安装包）
      └─ 大纲/写作/导出：outline/writer/exporter 移植，SSE 流式
```

## 4. 开放事项（后续切片前需产品决定）

- O1 支付资质：微信/支付宝商户号需营业执照等主体资质（人工办理，阻断自助支付切片）；无资质时 MVP 用兑换码/人工开通。
- O2 定价：单项目价格、订阅档位/价格/期限、各档包含配额。
- O3 HTTPS 方案：无 ICP 下 MVP 用自签证书 + 客户端指纹固定（或改海外区 + 域名）。
- O4 MSI 代码签名：不签名会有 SmartScreen 警告；签名证书为额外采购项。
- O5 平台供应的 LLM 模型清单与单用户成本上限。
- O6 订阅权益细节（并发、章节修改次数、导出格式等是否设限）。

## 5. 范围边界（明确不做）

- 不做离线模式；
- 不做移动端/Web 版（桌面优先，架构不排斥日后扩展）;
- 不在安装包内分发任何 generic_knowledge 内容；
- Streamlit 旧入口保留至桌面版发布后另行决定退役。
