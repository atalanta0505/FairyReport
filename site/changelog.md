## 🚀 v1.6.1 (2026-09-29) — 智库专报目录保真与 DeepSeek 官方生态对齐

### ✨ 核心修复与能力优化
- **智库专报 Word 导出多层标题防线加固（根治“第二章/标题二”丢失）**：
  - **章节序号精准反查**：升级 `_resolve_chapter_seq`，支持从公文序号（一、二、...）与完整大纲结构精确反查章序号，确保全章节骨架（`skeleton`）100% 注入提示词并锁定。
  - **流式提示词红线注入**：严格约束模型输出首行必须为 `# {chapter_title}` 一级标题，随后空行再写二级小节。
  - **合并导出自动防线**：在 `build_merged_md` 全书合并逻辑中加入大纲映射机制，当检测到章节正文首行缺失 `# 一级标题` 时，自动从 `outline.json` 补齐 `# {chapter_title}\n\n`，彻底杜绝小节越级挂靠。
  - **公文序号样式兼容**：`_parse_md_line` 扩展支持无 `#` 的标准公文序号标题，精准映射 Word `Heading 1` 并在目录页（TOC）生成条目。
- **DeepSeek 官方 API 与模型生态升级**：
  - **官方 Base URL 纠偏**：默认 Base URL 纠偏为官方规范 `https://api.deepseek.com`（移除冗余 `/v1`）。
  - **官方推荐模型更新**：默认模型更正为最新官方规范 `deepseek-flash`，移除已废弃的占位符命名。
  - **动态获取最新模型能力**：设置界面新增「🔄 获取最新模型」端点测试与实时拉取按钮，支持 `<datalist>` 智能下拉提示与手动自定义并存。
- **术语规范与安全认知强化**：
  - 全站与各向导文档彻底废除“上传”表述，统一规范为“本地导入/导入”，强化“数据不出域、底稿不传云”的物理隔离安全属性。
- **项目瘦身与陈旧产物清理**：
  - 清理历史旧版打包产物、孤立脚本与废弃依赖，释放超 800MB 空间。
- **全量测试回归**：
