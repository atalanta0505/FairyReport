# 5 分钟极速新手指南 🚀

欢迎使用 **FairyReport**！本教程专为**没有任何软件开发背景、刚接触投资项目或工程技术业务的新人**打造。

不需要懂编程、不需要配置复杂环境。阅读本文只需 5 分钟，你就能生成一份规范、专业、带国家标准三线表和正规格式的报告初稿！

---

## 🎯 极速体验案例：智库专报

在真实工作中，当我们面临新课题、宏观产业调研或建言献策时，手头往往**还没有收集到现成的项目文档资料**。

FairyReport 内置的「**智库专报**」类型支持**项目资料留空**直接创作——它会自动依托后台的**权威通用规程库**并结合**实时联网智识检索**，完成一份高质量报告！

让我们以此为例走一遍完整流程：

---

### 第一步：新建项目（资料留空即可）

1. 启动 FairyReport 客户端，点击主界面右上角的 **「新建项目」** 按钮。
2. 填写项目基本信息：
   - **项目名称**：例如输入 `国家算力枢纽绿色低碳发展建言报告`
   - **行业领域**：选择 `电子信息 / 节能低碳`
   - **实施地点**：选择或填写 `全国 / 重点枢纽节点`
3. **上传资料**：本例中直接**保持留空**（无需上传任何文件），点击 **「创建」** 即可。

::: tip 💡 为什么要支持“资料留空”？
对于可行性研究、技术方案等工程类报告，上传项目批复、立项建议书等资料可以实现更精准的项目数值提取；但对于政策建言、智库专报等宏观课题，手头无现成资料时，系统内置的三源联网 RAG 能自动补齐权威背景与实时动态。
:::

---

### 第二步：选择模板，一键生成大纲

1. 点击顶部进度条的 **「2. 大纲」** 步骤。
2. 在左侧报告类型中，选中 **「智库专报」**。
3. 点击 **「生成大纲」** 按钮。系统将在数秒内根据国家发改委标准体例，自动规划结构严谨的多级目录章节：
   - 一、引言与背景：国家战略与枢纽算力发展现状
   - 二、现实挑战与核心制约
   - 三、国际经验借鉴与对标分析
   - 四、关键举措与实施路径建议
   - 五、效益预期与政策保障措施

### 第三步：点击「一键全篇撰写」，静待生成

1. 切换至顶部 **「3. 撰写」** 步骤。
2. 点击 **「一键全篇撰写」**（或点击各章节旁的“撰写”图标单独生成）。
3. 界面将呈现流式打字机效果，实时输出专业内容：
   - **自动嵌入标准工程三线表**：如《全国绿色算力中心能效 PUE 指标对比分析表》。
   - **附带角标溯源**：在专业论据后方自动标注来源标签。

### 第四步：专家多维审阅，一键采纳建议

1. 进入 **「4. 审阅」** 步骤。
2. 点击 **「开始专家审阅」**。系统将模拟资深咨询专家的视角，从以下维度进行严格把关：
   - **数据完备性**：指标是否具体翔实。
   - **政策契合度**：是否紧扣国家发改委最新指导文件。
   - **措施可行性**：提出的对策建议是否具备可操作性。
3. 右侧审阅抽屉会列出每章节的具体修改意见，点击 **「采纳建议」**，系统将自动对正文进行润色强化。

### 第五步：自洽性核验与出版级 Word 导出

1. 进入 **「5. 导出」** 步骤。
2. 系统会自动执行跨章节一致性与自洽性核验，给出满分通过评估。
3. 点击 **「导出为 Word 文档 (.docx)」**。
4. 打开生成的 Word 文档，你会发现：
   - ✅ 已经自动应用封面与层级目录格式。
   - ✅ 正文为标准仿宋/宋体与公文级行间距。
   - ✅ 表格完美转为符合国家标准规范的顶线、底线粗、栏目线细的**三线表**。
   - ✅ 可以直接作为合规初稿向团队或领导提交汇报！

## 🔑 首次使用：设置大模型 API Key

系统目前支持 **DeepSeek 系列模型**（推荐使用官方最新模型）：

1. 打开应用右上角 **「设置」**（齿轮图标）。
2. 在 **API Key** 输入框中，粘贴你的 DeepSeek API Key（从 DeepSeek 开放平台申请）。
3. 接口地址保持默认 `https://api.deepseek.com/v1`。
4. 模型选择推荐的 DeepSeek 官方最新模型。
5. 点击 **「保存配置」** 即可。

::: warning 🔒 数据安全提示
你的 API Key 仅保存在本机本地配置文件中，绝对不会上传到任何第三方或公共服务器。
:::
