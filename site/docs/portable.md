# 绿色免安装便携版运行指南 📦

为了让非技术背景的业务人员免去繁重的开发环境配置，FairyReport 提供了完全自包含的 **Windows x64 绿色免安装便携版**。

---

## 🎯 便携版核心特性

- **零环境依赖**：无需安装 Python、Node.js、Rust 或 Visual Studio C++ 运行库。
- **免管理员权限**：无需管理员（Administrator）权限安装，支持任意普通非受限目录运行，可直接存放于 U 盘移动办公。
- **即启即用**：双击启动，前端桌面与后端计算引擎全自动调度接驳。

---

## 🚀 快速启动三步法

### 1. 下载与解压缩
前往 [客户端下载中心](/download) 获取最新版 `FairyReport-Local-v1.5.0-Windows-x64.zip`。  
下载完成后，右键选择 **「解压到当前文件夹」**。建议解压至空间充足的纯英文或非深层目录（例如 `D:\FairyReport\`）。

### 2. 双击启动
进入解压后的文件夹，双击运行：
```text
FairyReport.exe
```
程序启动时会自动唤起本地轻量计算引擎，并在数秒内加载出主窗口界面。

### 3. 配置大模型密钥
首次启动后：
1. 点击右上角 **「设置」** 图标。
2. 填入你的大模型 **API Key**（如 DeepSeek API 密钥）。
3. 接口地址保持默认（`https://api.deepseek.com/v1`）即可。
4. 点击 **「保存配置」**，即可永久生效，立刻开始创建项目。

## 💾 数据存储与迁移备份

- **数据存储目录**：所有创建的项目、上传的文档切片和历史生成记录，默认保存在当前用户的本地磁盘目录：
  ```text
  C:\Users\<你的用户名>\AppData\Local\FairyReport\
  ```
- **完整备份迁移**：如果你需要更换电脑或移动办公，只需复制上述 `AppData\Local\FairyReport\` 文件夹到新电脑对应位置，所有项目进度与向量智识库即可完美迁移，无缝衔接。

## 🛠️ 常见启动问题排查

::: details 1. Windows Defender 或杀毒软件弹出网络访问提示？
**解答**：FairyReport 前后端之间采用本地内部回环端口（`127.0.0.1:8000`）进行高速安全数据交换。系统弹窗是在询问是否允许本地进程间通信。请放心地点击 **「允许访问」**。
:::

::: details 2. 双击后提示端口被占用？
**解答**：如果你的电脑上刚好有其他服务占用了 `8000` 端口，可在应用程序根目录的配置文件或环境变量中指定自定义端口号，例如设置 `PORT=8005`，重新双击启动即可。
:::

::: details 3. 可以在离线局域网或断网机房中使用吗？
**解答**：可以！FairyReport 的文档解析、向量检索和前端排版完全离线运行。如需在无外网环境下撰写，只需在局域网内搭建 [Ollama](https://ollama.ai/) 本地大模型服务，并将 FairyReport 设置中的 API 地址指向该局域网 IP（例如 `http://192.168.1.100:11434/v1`）即可。
:::
