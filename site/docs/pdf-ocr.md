# 扫描件 PDF 离线 OCR 处理指南 📄

在工程项目前期资料收集过程中，经常会遇到由纸质复印件扫描生成的 PDF 文档（如早期的土地预审意见、红线图说明、立项批复扫描件等）。

---

## 🔍 为什么扫描件 PDF 需要提前 OCR？

PDF 文件在技术上主要分为两类：
1. **可搜索文本 PDF（电子原生版）**：由 Word、WPS 或 AutoCAD 直接“导出为 PDF”生成。这类文件内部包含完整的字模与字符编码，FairyReport 可以直接以毫秒级速度提取其中的全部文字与表格。
2. **纯图片扫描件 PDF**：由扫描仪或手机拍照生成。这类文件本质上是由多张位图图片串联而成，文档内部**没有字符编码**。如果直接导入，解析引擎只能读取到图片数据而提取不到正文字符。

为了让 FairyReport 能够深入理解扫描件中的内容并作为底稿进行向量检索，需要先对这类图片型文档进行一次**光学字符识别（OCR）**。

---

## 🛠️ 推荐的高效轻量 OCR 工具

推荐使用以下几种简单易用且保护商业隐私的工具：

### 方案一：使用开源离线 OCR 工具（强烈推荐 · 隐私安全）
- **Umi-OCR 离线文本识别软件**（免费开源、纯本地运行）：
  - 支持直接将 PDF 批量识别为可搜索 PDF 或 `.txt` / `.docx`。
  - 完全断网运行，底稿数据绝对不离开电脑，非常契合工程保密要求。
- **RapidOCR / PaddleOCR 本地桌面端**：
  - 识别速度极快，对工程表格、中文公文排版有很高的识别准确率。

### 方案二：使用常见办公软件自带 OCR
- **Adobe Acrobat Pro / 福昕高级 PDF 编辑器**：
  - 打开扫描件后，点击菜单中的 **「工具」➔「文本识别 (OCR)」➔「在当前文件中」**。
  - 识别完成后直接点击保存，原 PDF 即可转为包含文本层的**可搜索 PDF**。直接导入 FairyReport 即可被完美解析。
- **微信 / QQ 截图识图**：
  - 适合篇幅较短（1~3 页）的关键批复文件。直接在电脑端截图后点击“翻译/识别文字”，复制保存为文本文件或 Word 导入。

---

## 📥 导入 FairyReport 的最佳实践

1. **优先输出为带有文本层的可搜索 PDF**：保持原有排版格式，导入时能最好地保留页码和章节结构。
2. **或直接另存为 Word / Markdown**：便于人工对扫描识别中的个别错别字（如生僻地名、数字小数点）进行简单校核。
3. 导入 FairyReport 后，可在左侧材料列表查看各切片的文字分块预览，确认文本已被完整抓取即可。
