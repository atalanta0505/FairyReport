# 扫描件 PDF 离线 OCR 处理指南 📄

在工程项目前期资料收集过程中，经常会遇到由纸质复印件扫描生成的 PDF 文档（如早期的土地预审意见、红线图说明、立项批复扫描件等）。

---

## 🔍 为什么扫描件 PDF 需要提前 OCR？

PDF 文件在技术上主要分为两类：
1. **可搜索文本 PDF（电子原生版）**：由 Word、WPS 或 AutoCAD 直接“导出为 PDF”生成。这类文件内部包含完整的字模与字符编码，FairyReport 可以直接以毫秒级速度提取其中的全部文字与表格。
2. **纯图片扫描件 PDF**：由扫描仪或手机拍照生成。这类文件本质上是由多张位图图片串联而成，文档内部**没有字符编码**。如果直接导入，解析引擎只能读取到图片数据而提取不到正文字符。

为了让 FairyReport 能够深入理解扫描件中的内容并作为底稿进行向量检索，需要先对这类图片型文档进行一次**光学字符识别（OCR）或文档智能解析**。

## 🛠️ 推荐的免费、开源且带可视化界面 (UI) 的好工具

我们为您精选了 **完全免费、带有友好图形界面（无需敲命令行）、上手极简单** 的优质工具：

### 方案一：MinerU（开源高质量 PDF 智能解析神器 · 强烈推荐 🌟）
- **工具简介**：由 OpenDataLab 开源的旗舰级文档解析工具，专为包含复杂工程表格、多栏排版、公式与图表的技术报告和扫描件 PDF 打造。
- **核心优势**：
  - **直接输出结构化 Markdown (`.md`)**：不仅能精准识别扫描件文字，还能将复杂的跨页工程表格、章节标题完美还原为结构化 Markdown 文件——而 `.md` 正是导入 FairyReport 效果最佳的黄金格式！
  - **完全免费且有直观 UI**：提供官方免费在线可视化工作台（浏览器打开直接拖拽 PDF 即可解析导出），同时也提供开箱即用的桌面客户端界面，零代码门槛。

### 方案二：Umi-OCR（免费开源 · 纯本地离线图形界面软件 🔒）
- **工具简介**：广受好评的免费开源离线 OCR 桌面软件（Windows 绿色免安装，解压双击即可打开图形界面）。
- **核心优势**：
  - **100% 纯本地断网运行**：无需联网、完全免费，敏感工程底稿数据绝不离开本机，完美契合涉密或高保密工程项目要求。
  - **傻瓜式批量转换**：打开软件切换至「批量文档」标签页，直接把扫描件 PDF 拖入窗口，一键即可导出为 **双层可搜索 PDF** 或 `.txt` / `.md` 文档，随后直接拖入 FairyReport 即可。

### 方案三：电脑端微信 / QQ 内置「提取文字」（零安装 · 短篇批复首选 💬）
- **适用场景**：适合篇幅较短（1～5 页）的立项批复红头文件、用地预审意见或函件扫描件。
- **操作方法**：完全无需额外下载软件，直接用电脑端微信或 QQ 截图（或打开扫描图片），点击工具栏上的 **「提取文字」**，一键复制识别出的文字并粘贴保存为 `.txt` 或 `.docx` 导入 FairyReport。

## 📥 导入 FairyReport 的最佳实践

1. **复杂长篇扫描报告优先用 MinerU 转为 Markdown (`.md`)**：能最大程度保留原报告的表格行列结构与标题层级，向量检索精度最高。
2. **保密项目批量扫描件优先用 Umi-OCR 转为「可搜索 PDF」或 `.txt`**：全程在本机离线完成，兼顾速度与数据隐私。
3. 导入 FairyReport 后，可在项目资料列表中核对文件解析状态，确认文本已被完整提取即可开始生成大纲与正文。
